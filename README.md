## 📝 Code Style Guidelines

Following these conventions throughout the project:

```python
# Use descriptive variable names
user_age = 25  # ✅ Good
ua = 25        # ❌ Avoid

# Add comments for complex logic
# Calculate circle's area using the formula A = πr²
area = math.pi * (radius ** 2)

# Use proper spacing
x = 2 + 3      # ✅ Good
x=2+3          # ❌ Avoid

# Follow PEP 8 naming conventions
def calculate_average():  # Functions: snake_case
    pass

class Calculator:         # Classes: PascalCase
    pass

CONSTANT_VALUE = 100      # Constants: UPPER_CASE
```
